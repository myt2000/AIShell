## 1. 界面总览

### 1.1 左侧「服务器树」面板

面板顶部是 **AIShell 工具按钮栏**，从左到右 6 个按钮：

| 图标 | 功能 |
|---|---|
| 🪄 魔法棒 | 从模板新建 |

| 📡 信号塔 | 批量命令 |
| 🤖 机器人 | AI 助手 |

工具按钮下方是**过滤框**，再往下是**服务器树**（分组层级结构）与**批量操作条**。

### 1.2 入口速查

## 2. 首次上手（三步）

### 第一步：填写服务器登录配置

1. 点左侧树面板「获取服务器配置」按钮，打开弹窗。
2. 点弹窗顶部的 **「服务器登录配置」** 折叠按钮展开。
3. 填写以下字段：

   | 字段 | 说明 |
   |---|---|
   | 监控平台地址 | 默认 `http://172.16.14.123:8080/` |
   | 监控平台账号 / 密码 | 登录监控平台用的账号密码 |
   | 堡垒机用户名 / 密码 | 连接堡垒机用的账号密码 |
   | 目标服务器用户名 / 密码 | 从堡垒机跳转到目标机用的账号密码 |
   | 杭州三墩 / 北京马驹桥 / 无锡国际 堡垒机 IP | 三个机房各自的堡垒机地址 |

4. 点 **「保存登录配置」**。非敏感信息写入 Tabby 配置，**三个密码加密存入系统凭据管理器**（macOS 钥匙串 / Windows 凭据管理器），配置文件里不留明文。

> 如果之前用过 `login.env` 文件，第一次打开此弹窗时会自动弹出「已从 login.env 导入服务器登录配置」的提示，之后无需再维护该文件。

### 第二步：拉取并生成文件树

1. 确认「每页数量」（默认 100）。
2. 点 **「获取全部配置」**，等待遍历完成（进度条会显示「机房 / 产品 / 模块，第 X / Y 页」和已获取台数）。
3. 预览表确认无误后，点 **「生成文件树」**。
4. 完成后左侧服务器树会出现「机房 / 产品 / 模块」三层分组，每个存活节点对应一条 SSH 连接。

### 第三步：连接服务器

双击树中的服务器节点，或点节点右侧的 ▶ 按钮即可连接。连接时会自动：

- 用堡垒机账号登录；
- `ssh 目标用户@目标IP` 跳转到目标机；
- 输入 `$TARGET_PASSWORD`（从凭据管理器注入，界面看不到明文）；
- `cd /app/newgetui/<模块>/logs` 进入日志目录。

## 3. 服务器清单同步

「获取服务器配置」弹窗 = 从监控平台同步服务器清单 + 生成 SSH 文件树 + 导出 CSV。

### 3.1 拉取清单

- 校验：平台地址需以 `http://` / `https://` 开头；必须填监控平台账号密码。
- 拉取过程**遍历全部机房、产品、模块、分页**，不依赖监控平台下拉框当前选中状态，不会漏节点。
- 可随时点「停止」中断。

### 3.2 导出 CSV

点 **「导出 CSV」** 下载 `server-inventory-YYYY-MM-DD.csv`，列包含：机房、机房ID、产品、产品ID、模块、模块ID、节点名称、JMX地址、JMX端口、连接状态。带 BOM，中文 Excel 直接打开不乱码。

### 3.3 生成文件树

点 **「生成文件树」** 前会校验：堡垒机用户名/密码、目标机用户名/密码、至少一个机房堡垒机 IP 都已保存，否则提示并自动展开登录配置区。

生成逻辑：

- 只处理「存活 + 有 JMX 地址」的节点，异常节点跳过并计数；
- 生成「机房 / 产品 / 模块」三层分组（幂等，已存在的分组复用）；
- 只为**本工具生成的 profile** 做增删改，通过 `aishell:syncSource` / `aishell:syncKey` 标记，不动你手工建的连接；
- 同步后自动清理清单里已消失的旧节点 profile；
- 结果提示「新增 X 台，更新 Y 台，跳过异常 Z 台」。

## 4. 服务器树操作

### 4.1 多选

- 单击选中/取消单个节点；
- 按住 **Ctrl / Cmd** 单击可多选；
- 选中后顶部出现**批量操作条**：

| 按钮 | 作用 |
|---|---|
| ▶ 连接选中 | 依次连接所有选中服务器 |
| 📁 移动到分组 | 把选中项批量移动到指定分组 |
| ⧉ 复制选中 | 复制选中项（副本名称加 ` copy` 后缀） |
| 🗑 删除选中 | 批量删除（二次确认） |
| ✕ 清除选择 | 取消全部选中 |

### 4.2 拖拽

- 拖动服务器节点到另一个分组 → 移动；
- 拖动分组头到另一个分组头 → 把分组重新挂载为子分组；
- 拖到树底部「拖到此处 → 移到顶层」区域 → 移出分组（未分组）。
- 说明：组内节点按名称排序，拖拽只支持跨分组移动与分组重挂，暂不支持组内排序。

### 4.3 右键菜单

- **服务器节点右键**：连接、编辑、复制、删除、**批量修改登录密码…**（单台也走批量弹窗）等。
- **分组右键**：新建分组、重命名、删除、**批量修改登录密码…**（作用于整个文件夹，含子文件夹）等。

## 5. 连接模板

模板 = 一组「预设连接选项」（Keepalive、登录脚本、跳板机、自定义变量等），可批量实例化为真实连接，并能把后续改动同步回所有派生连接。

### 5.1 新建模板

1. 树面板点「管理模板」。
2. 输入模板名，点「创建模板」——此时会自动用「编辑连接」弹窗打开该模板，让你配置 options（Keepalive、登录脚本等）。
3. 保存后模板出现在列表里。

### 5.2 设置模板变量

1. 在模板列表点该行的「$」按钮。
2. 在「Variables for: 模板名 (KEY=VALUE)」文本框里按行写 `KEY=VALUE`，例如：

   ```text
   ENV=prod
   ROLE=web
   ```

3. 点「保存」。这些变量会在实例化时替换进登录脚本等位置（见 [变量替换](#8-变量替换)）。

### 5.3 从模板批量新建

1. 树面板点「从模板新建」。
2. 选择模板。
3. 在「服务器清单」文本框粘贴服务器列表，**每行一台**，支持：

   ```
   host                # 例如 10.0.0.1
   user@host           # root@10.0.0.2
   host:port           # 10.0.0.3:2222
   user@host:port      # root@10.0.0.4:2222
   user@host:port #备注 # 行尾 # 为备注名
   ```

   下方会实时显示「已解析 N 台」，识别不了的行会单独标出。

4. 选择目标分组（或「未分组」）。
5. 点「创建」。生成的连接会记录 `aishell:templateId` 关联回模板。

### 5.4 同步模板到派生连接

修改模板后，在「管理模板」列表点该行的「🔄 同步」按钮 → 确认，模板的 options 会重新应用到所有派生连接（跳过 `host/port/user/password` 等实例专属字段）。

## 6. 批量命令

1. 树面板点「批量命令」。
2. 顶部勾选要发送的**已打开且连接就绪**的终端窗口（不会自动去连新服务器），可点「刷新」重新拉取。
3. 在命令框输入命令，**一行一条**，支持 `$SERVER_IP` / `$SERVER_NAME` 等变量，每个目标单独替换。
4. 点「发送」。

- 若命令匹配危险模式（`rm -rf`、`mkfs`、`reboot`、`dd if=`、fork 炸弹等），会弹二次确认。
- 发送后弹窗立即关闭，命令在后台按目标逐个发送（每窗口内行间有 120ms 间隔），结果以通知呈现「已发送到 N 个目标 / 发送到 X/N 个目标」。

## 7. 键盘广播

SecureCRT 式「发送输入到所有标签页」：

1. 在任意终端标签页**右键 → 发送输入到所有标签页**（勾选开关）。
2. 之后你在当前标签敲的每个字符都会原样转发到其他**已连接**的终端标签。
3. 切换活动标签自动重新挂载；再次点右键取消勾选即关闭。

适合对多台机器执行相同的交互式命令。

## 8. 变量替换

登录脚本、批量命令、模板实例化共用同一套变量引擎，支持 `$VAR` 与 `${VAR}` 两种写法。

### 8.1 内置变量

| 变量 | 含义 |
|---|---|
| `$SERVER_NAME` | 连接名 |
| `$SERVER_IP` / `$SERVER_HOST` | 主机地址 |
| `$SERVER_PORT` | 端口 |
| `$SERVER_USER` | 登录用户 |
| `$SERVER_GROUP` | 所在分组路径 |

### 8.2 自定义变量

模板或连接 `aishell:vars` 里定义的键值对，直接以 `$KEY` 引用。

### 8.3 特殊变量 `$TARGET_PASSWORD`

登录脚本里跳转目标机那一步的 `send` 写 `$TARGET_PASSWORD`，连接时会从系统凭据管理器注入真实密码，脚本文本里看不到明文。

## 9. 会话录制

把终端输出实时落盘到文件。

### 9.1 全局自动录制

1. AI 助手 → 设置（齿轮）→ 打开「AIShell 设置」。
2. 「会话录制」区打开 **Auto-record all terminal sessions**。
3. 可选：日志目录（默认 `~/AIShell/logs`）、剥离 ANSI 转义码、每行加本地时间戳前缀。

### 9.2 单标签手动录制

终端标签页右键 → **Record output to file**（再次点击为「停止录制」）。

### 9.3 行为

- 文件名 `{标签名}_{yyyyMMdd_HHmmss}.log`；
- 旁路记录，不影响终端渲染与清屏操作；
- 断开重连后自动续写同一文件。

## 10. 多窗口日志分析

把多个终端窗口 + 多个日志文件，合并成一条按时间排序的时间线，用于跨模块排查关联问题。

1. 树面板点「多窗口日志分析」。
2. 左侧「目标」区：
   - 勾选要纳入的**终端标签**（实时捕获其滚动缓冲）；
   - 或点「添加日志文件…」选择本地 `.log/.txt/.out` 文件（单文件最大读 512KB，超长取尾部）。
   - 设置「每窗口行数」（默认 300）。
3. 点 **「构建时间线」**：输出 `[时间] [模块] 日志内容`，无时间戳的行继承上一行时间。
4. 右侧工具栏：
   - **导出**：保存合并结果为 `.log`；
   - **AI 分析**：把合并时间线交给 AI，按时间顺序列出异常、跨模块时序关联与处置建议（超长自动「头 25% + 尾 75%」智能截断）。

## 11. AI 助手

### 11.1 首次配置

1. 树面板点「AI 助手」，弹窗右上角点**齿轮**进入「AIShell 设置」。
2. 「AI assistant」区：
   - 打开 **Enable AI assistant**；
   - 可直接点 **CC Switch** 一键对接本地代理（读取 `~/.claude/settings.json`），或选「Provider presets」预设，或手动填写；
   - 选择协议：**OpenAI**（`/chat/completions`，兼容 OpenAI/DeepSeek/通义/Ollama 等）或 **Anthropic / CC Switch**（`/v1/messages`）；
   - 填 Base URL、Model、API Key（本地模型可留空）、Max output tokens、Max context characters。
3. 「会话录制」区可一并配置（见 [会话录制](#9-会话录制)）。
4. 点「保存」。

> API key 明文存在本机 Tabby 配置里（`aishell.ai.apiKey`）。

### 11.2 对话

- 底部输入框直接提问，**Enter 发送、Shift+Enter 换行**；
- 上下文会自动附带：当前连接目标、已打开窗口数、服务器文件夹清单（名称/路径/台数），**不含任何密码密钥**；
- 右侧侧栏可「新建会话」、切换/删除历史会话（最多保留 50 个会话，单个会话最多 200 条消息，存在本地 localStorage）。

### 11.3 快捷动作

弹窗顶部四个快捷按钮：

| 按钮 | 作用 |
|---|---|
| 解释选中 | 把当前终端选中文本交给 AI 解释 |
| 诊断输出 | 诊断最近 150 行终端输出 |
| 分析日志 | 分析选中或最近 300 行输出 |
| 多窗口日志 | 打开多窗口日志分析工作台 |

### 11.4 AI 动作按钮

AI 回复里若带有可执行动作，会渲染成按钮，**点击并确认后才执行**（不会自动执行）：

- 「连接某文件夹下全部服务器」→ 逐个打开（每台间隔 700ms）；
- 「连接某台服务器」；
- 「在当前/全部窗口执行命令」→ 经过只读命令硬校验，拒绝任何写入/变更类命令；
- 「自动日志查询：xxx」→ 见 [自动日志查询](#12-自动日志查询)。

执行完「run」动作后若开启了「自动分析」（右上角圆圈对勾开关），会延时 9 秒自动抓取各窗口输出回传给 AI 继续分析。

### 11.5 消息操作

- 每条消息可「复制」（避开在终端焦点下按 Ctrl+C 被当作中断命令）；
- 自动日志查询结果附带**可下载日志档案**（按「模块-日志类型.log」聚合）。

## 12. 自动日志查询

在 AI 助手里输入类似：

```text
查询 task_id=RASS_0901_xxx，cid=32位cid 的消息下发情况
```

流程：

1. AI 识别 `task_id` / `cid` / `appid` / `日期` / `推送时间点` 等参数，输出一个 **「自动日志查询」动作按钮**。
2. 点按钮：
   - 若 `task_id` 前缀是 `GT_`（列表推 vs 全推不明确），先让你选「psc：列表推送」或「spd：全推」；
   - 弹「启动自动日志查询」确认框，展示任务、设备、起始模块、服务器、首条命令；
3. 点「开始」后本地规则引擎接管：
   - 按 `task_id` 前缀路由起始模块：`RASA/RAST→spd`、`RASL/RASS→psc`、`OSL/OSS/OSA→os`、`MM→mmp`；
   - 并行打开/复用候选服务器（优先级：用户指定 > 已打开窗口 > 机房 杭州→北京→无锡）；
   - 每个窗口执行**只读** `zgrep`/`find` 命令（命令由本地模板生成，AI 不生成 shell），并监听完成标记；
   - 按字段解析结果路由下一模块：在线链路 `im → cm → as`；离线 `SDP → 厂商模块 → gtpr`；离线 `OMP`；iOS `apn/apns → gpmrs → as` 等；
   - 全程只读，无法判断时暂停并提示人工核对，不编造结论。
4. 结束后：
   - 对话里输出「自动日志查询完成/已暂停」+ 每步摘要；
   - 提供按模块/日志类型聚合的**日志档案下载**；
   - 自动把结构化结果回传 AI，让 AI 给出一句话结论 + 分步判断依据。

> 规则细节、模块路径、字段含义见 [`docs/日志解析.md`](日志解析.md)。

## 13. 批量修改登录密码

用于把「SSH 连接密码」和「跳转目标机密码」批量更新并迁入系统凭据管理器，同时清掉配置里的明文。

1. 树面板右键：服务器节点 / 选中集 / 整个文件夹 → **批量修改登录密码…**。
2. 弹窗里：
   - **新 SSH 登录密码**：填了才会更新（下方显示影响 N 台）；
   - **新跳转目标机密码**：填了才会更新（下方显示影响 N 台）；
   - 范围区显示「作用范围 · N 台 profiles」。
3. 点「应用」：

   - SSH 密码 → 按 `user@host:port` 去重写入凭据管理器，并删除配置里的 `password` 字段；
   - 跳转密码 → 写入全局 `AIShell:target-jump` 凭据条目，并把登录脚本里的密码步骤统一改为 `$TARGET_PASSWORD` 变量引用。

## 14. 常见问题

**Q1：生成文件树提示「请先在服务器登录配置中填写堡垒机用户名和密码」？**
点弹窗顶部「服务器登录配置」展开，补全堡垒机用户名/密码、目标机用户名/密码、至少一个机房堡垒机 IP，再点「保存登录配置」。

**Q2：提示「未找到 login.env / 未获取到服务器登录配置」？**
新版优先读「设置 + 凭据管理器」；若两者都没有且没有 login.env 文件会报错。在「服务器登录配置」里填好保存即可，无需再用 login.env 文件。

**Q3：连接服务器卡在登录脚本、进不去日志目录？**
检查堡垒机/目标机账号密码是否正确（可在「批量修改登录密码」里重新设置）；部分老服务器需要旧版 DH KEX 算法，AIShell 已自动追加这些算法。

**Q4：AI 助手点了没反应 / 提示未配置？**
到「AIShell 设置」确认已启用、Base URL 与 Model 已填；OpenAI 协议需填 API Key，Anthropic/CC Switch 可留空走本地代理。

**Q5：自动日志查询提示「无法识别起始模块 / 无匹配日志」？**
确认 `task_id` 前缀正确（`RASS_`、`RASL_`、`GT_` 等）；`GT_` 任务需先选择推送类型；确认日期、服务器分组命名（机房/模块需能匹配）无误。

**Q6：配置里明明还有明文密码，为什么没自动迁移？**
明文迁移是**一次性**的（`aishell:securePasswords` 标记置位后不再重复）。可直接用「批量修改登录密码」主动把密码迁入凭据管理器并清掉明文。
