# 日志排查流程文档
介绍：当前查询日志分为3个板块
1. 消息推送日志查询

3. 短信日志查询

## 消息推送日志查询
### gtps-hw错误码
参考文档：https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/commonerror-0000001059816656

> 说明：华为推送错误码由「HMS Core SDK 框架错误码」和「HMS Core Push SDK 错误码」两部分组成。
> 排查顺序建议：先看 REST API 响应码（801xxxxx / 803xxxxx）确认云端是否正常下发，再看端侧错误码（9071xxxxx）。
> gtps-hw的日志主要查询的日志模块是rp-bi，rp-message, push-result, rp-broadcasting

#### 错误码详情与解决方法

**-5 获取 Token 任务失败**
- 检查混淆配置脚本，确保 HMS 相关类未被混淆。

**502 请求连接异常**
- 常见于网络状况不稳定，建议稍后重试，或联系技术支持。

**503 流量控制**
- 平均分配发送速度，控制在华为提供的 QPS 配额内。
- 平均分布推送时间段，不要集中发送。

**6003 指纹证书配置不一致**
- 确认证书指纹端云配置一致：客户端应用打包的证书和在 AppGallery Connect 上配置的"SHA256证书指纹"一致。
- HMS Core（APK）会缓存签名文件，需在"应用管理"中找到 HMS Core 清理掉缓存数据，然后重新打开应用尝试。

**6004 接口鉴权时，权限不存在**
- 检查当前应用是否已正常开启相关服务；未申请的请完成开启。
- 已申请的建议将服务开关关闭后重新开启，等待约 30 分钟。
- 手机客户端清除 HMS Core 缓存后重启测试（手机设置 > 应用 > 应用管理 > HMS Core > 存储 > 清除数据和缓存）。

**80100003 消息结构体错误**
- 根据响应消息中的提示，检查消息结构体的参数并修改。

**80100016 消息体中带有敏感词汇**
- 检查发送消息内容。

**80300002 下发消息给指定用户（Token）报无权限**
- 登录 AppGallery Connect，查看推送服务状态是否已开通。
- OAuth 2.0 客户端模式（SDK 2.0）：把 Access Token 里的转义字符（\）去掉后再进行 URL Encode 编码。
- 检查用户的 Token 与鉴权令牌使用的应用/项目信息是否一致。
- 国内推送正常但海外返回 80300002：需开通海外 Push 权益（AppGallery Connect > 项目设置 > API 管理 > 关闭 Push 服务后重新启用）。
- 可先在推送运营平台推送测试，成功则说明是调用接口时出错。

**80300007 指定的 Token 无效**
- 同一设备不同应用的 Token 不一样，检查是否误传了同样的值。
- 检查客户端应用配置的包名、应用 ID 与 AppGallery Connect 上申请的是否一致。
- 检查鉴权信息与 Token 所属应用/项目是否一致。
- 检查消息发送 URL 是否正确：
  - SDK 2.0：`https://api.push.hicloud.com/pushsend.do`
  - SDK 3.0+：`https://push-api.cloud.huawei.com/v1/[clientid]/messages:send`
- 终端设备未安装 HMS Core（APK）或版本过低，在华为应用市场手动搜索 HMS Core 安装后测试。

**907122036 没有开通推送权益**
- 检查当前应用是否已正常开启相关服务。

**907122046 Push 不可服务**
- 联系技术支持解决。

**907122047 通用错误码**
- 错误场景较多，请联系技术支持解决。

**907122054 Push SDK 自动初始化中**
- 稍后重试操作。
- 终端设备未安装 HMS Core（APK）或版本过低，在华为应用市场手动搜索 HMS Core 安装后测试。

**907122069 不支持子用户操作**
- 仅终端设备机主可以使用，请切换到机主用户后使用。

**907135000 传入的参数错误**
- 检查 `agconnect-services.json` 文件中的 app_id、package_name 参数是否正确。
- 检查 `build.gradle` 文件中证书签名是否配置。
- 可能是 HMS Core（APK）缓存导致：卸载重装 HMS Core，断网再连接，重新打开应用。
- 建议先用华为终端测试（华为推送依赖 HMS Core，华为手机预装，非华为手机没有预装）。

**907135003 SDK 连接 HMS Core（APK）失败**
- 可能是 HMS Core 进程被终止或崩溃导致连接失败，稍后再试。
- 可能是终端设备未安装 HMS Core（APK）或版本过低，在华为应用市场手动搜索 HMS Core 安装后测试。

**907135702 OpenGW 没有配置指纹证书**
- 检查手机网络是否可正常访问互联网。
- 登录 AppGallery Connect，在"项目设置 > 常规"中检查"SHA256证书指纹"配置的信息是否和根据签名文件生成的指纹证书一致，不一致请修改。

#### 常见错误码分类说明

**HTTP 状态码（200 ~ 503）**

| 响应码 | 说明 | 处理建议 |
|---|---|---|
| 200 | 成功 | — |
| 400 | 参数错误 | 根据响应内容中的错误码进一步排查 |
| 403 | 鉴权不通过 | 检查 Access Token 是否正确 |
| 404 | 找不到服务 | 检查请求 URI 是否正确 |
| 500 | 服务内部错误 | 检查请求方式和报文格式，仍未解决则反馈到 honorpush@honor.com |
| 502 | 请求连接异常 | 网络不稳定，稍后重试 |
| 503 | 流量控制 | 超出 QPS 限制（单应用统一 3000），稍后再试 |

**业务错误码 - Token 相关（80100000, 80300006 ~ 80300010）**

| 响应码 | 说明 | 处理建议 |
|---|---|---|
| 80100000 | 部分Token发送成功 | 检查返回值中发送失败的 Push Token |
| 80300006 | Push Token 重复 | 检查是否有重复的 Push Token |
| 80300007 | 所有 Push Token 无效 | 检查包名/应用ID是否与申请一致，检查 access_token URL 和消息发送 URL 是否正确 |
| 80300008 | 消息体超过 4096Bytes | 减小消息体后重新发送 |
| 80300010 | Push Token 数量超过 1000 | 检查每次推送的 Token 数量 |

**业务错误码 - 消息内容与权限（80100003, 802000xx）**

| 响应码 | 说明 | 处理建议 |
|---|---|---|
| 80100003 | 消息结构体错误 | 按响应消息提示检查消息结构体参数 |
| 80200020 | receiptId 不匹配 | 检查 receiptId |
| 80200022 | 应用无权限发送该类型消息 | 检查资讯营销类消息是否设置了 image 字段（仅服务通讯类消息支持） |
| 80200047 | 测试消息达到当天上限 | 发送正式消息或隔天再试 |
| 80200050 | 资讯营销类消息不支持 image 字段 | 检查是否误设了 image 字段 |
| 80200056 | 消息标题或内容包含敏感信息 | 检查消息标题和内容 |

**业务错误码 - 参数校验（10001 ~ 10300）**

| 响应码 | 说明 | 处理建议 |
|---|---|---|
| 10001 | timestamp 为空 | 检查 timestamp 参数 |
| 10205 | appId 不存在 | 检查 appId 是否正确 |
| 10207 | timestamp 不合法 | 获取当前有效的 timestamp 并检查合法性 |
| 10300 | Push Token 为空 | 填写 Push Token |
